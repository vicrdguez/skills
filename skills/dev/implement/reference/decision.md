# Decision Result Document

Write `decision.md` in the packet's private Result Document directory. The semantic command carries the permitted decision reason separately; the engine publishes this prose unchanged.

## Human Decision

State the frozen requirement or mandatory rule that blocks progress, the current Workflow State, and the work already completed. Describe the options, their consequences, and your recommendation. When implementation exists, also write `submission.md` in this directory and push the branch so a draft Submission preserves the work.
